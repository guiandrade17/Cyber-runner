# 🎮 Cyber Runner/Neon Escape v2.0
Link do Jogo: https://guiandrade17.github.io/Cyber-runner/

Um jogo arcade futurista desenvolvido com **HTML5 Canvas, CSS3 e JavaScript puro**, inspirado em estéticas cyberpunk e jogos endless runner.

---

## 🚀 Sobre o Projeto

Cyber Runner é um jogo 2D estilo endless runner com visual neon/cyberpunk, efeitos visuais avançados e gameplay dinâmica.

O jogador precisa:

* desviar de obstáculos;
* usar dash e double jump;
* coletar power-ups;
* sobreviver o máximo possível;
* alcançar novos recordes.

O projeto foi desenvolvido com foco em:

* arquitetura modular;
* organização de código;
* efeitos visuais modernos;
* física básica;
* manipulação avançada do Canvas;
* game loop com `requestAnimationFrame`.
